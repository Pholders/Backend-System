PHolders — what we built, and whether it works

PHolders is four apps that pass one job between them: a patient finds a doctor, books, pays, the doctor writes a prescription and signs it, a pharmacy fills it. Below is every part of that we have built, written as something you can actually go and try. Mark each one Pass, Fail or Blocked, and leave a note if something looks wrong — we read the notes and fix what they raise.

How to use this page. There are two parts. The main journey is numbered — do those in order, because each step needs the one before it to have worked, and that same order is how we demonstrate the product. The standalone tests underneath are not part of that journey; each one stands alone and can be done at any time, on its own, by one person.

Three buttons per line. Pass if it did what the line says. Fail if it did something else. Blocked if you could not get far enough to find out. Everyone with this link sees the same marks, straight away.

Notes are the useful part. Tap Add a note on any line to tell us what you saw. That is what we work from, so a sentence in your own words beats a Fail on its own.

What each app does

Doctor

BUILT

Sign up, set a fee and consulting hours, be found by patients, take bookings, write and sign prescriptions, see when a pharmacy has filled one, collect ratings.

Patient

BUILT

Find doctors nearby, book a time, pay by cash, card or medical aid, read prescriptions, send one to a pharmacy, set reminders, rate the doctor.

Pharmacy

BUILT · SCREENS NOT YET USED

See prescriptions sent to it, claim and fill them, run orders through to collection. The behind-the-scenes side is proven; nobody has clicked through the screens yet.

Admin

BUILT

The pharmacy directory: approve, suspend, group them, record agreements, and decide where claims go.

Known gaps — please don't log these

  • Reminders only go out by email. Text messages and phone notifications are not switched on yet.
  • A prescription's QR code works, but the link next to it will not open until the doctor website is published.
  • Nothing in the system creates invoices yet, so there is no invoice to attach a document to. Medical aid claims do work.
  • Pharmacy stock keeping does not exist yet — there is nothing behind that screen.
  • Repeat prescriptions are not built.
  • Sick notes are not built. They are a requirement, but not for this phase.
  • The doctor's own billing screens show sample figures. Billing is deliberately out of this phase.
  • Patient medical records that any doctor can read are phase 3, not now.
  • A doctor cannot change a prescription once it is signed. That is the law, and deliberate — cancelling it is the only way back.
  • Doctors do not dispense. Pharmacies fill prescriptions; the doctor only sees that it happened.
  • On the sign-up form the clinic address needs a place name, like “Sandton”, not a full street address.
